## Summary

Watchdocs is a GitHub App. It reads API code and documentation in the repositories you connect, edits documentation, and opens pull requests. It does not sell your data, and it does not use your code or documentation to train models.

## What we collect

**Account data.** Your GitHub login, id, email, and the installations you connect when you sign in.

**Repository data.** The repositories you connect, their default branches, your settings, and run metadata such as commit SHAs, endpoints touched, files edited, token usage, and cost. We store run metadata; we do not store your source code or documentation content.

**Usage data.** Monthly counts of opened and updated pull requests for billing.

**Waitlist data.** The email address and API description you submit through the waitlist form.

## How we use it

- To run the service: process pushes, edit documentation, open pull requests, and show run history.
- To bill you on the plan you choose.
- To send you service and waitlist emails.

## What we do not do

- We do not sell or rent your data.
- We do not train models on your code or documentation.
- We do not merge pull requests. Merging is always performed by a human on your repository.

## Content sent to the model

When the semantic gate detects a public contract change, the changed diff, the ranked documentation pages, and test fixtures from your repository are sent to the configured large language model to produce edits. This is how the product works; there is no way to use Watchdocs without this step.

## Retention and deletion

Run metadata is kept so the dashboard can show history. You can delete your account and all associated data from **Settings** at any time. GitHub App installations are not removed from your GitHub account when you delete your Watchdocs data.

## Data access

Only Watchdocs operators and the billing processor (Stripe) have access to the data required to operate the service. Payment information is handled by Stripe and is never stored by Watchdocs.
